A small set of tools built from the kind of work an IT Systems Operations Engineer does every day — checking connectivity, working out subnets, generating credentials safely. Everything here either runs entirely in your own browser, or reads information Cloudflare's network already sees for every request it handles — nothing on this page is stored, logged, or sent anywhere beyond what's needed to render the result to you.
