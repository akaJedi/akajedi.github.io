**Какие типы данных есть в PHP ?**
*Спросят с вероятностью 33%*

<!--more-->


Есть несколько основных типов данных, каждый из которых служит определённым целям при программировании. Типы данных можно разделить на три основные категории: простые (или скалярные) типы, составные типы и специальные типы.

Простые (скалярные) типы
1️⃣**Integer (целое число)** — представляет собой целое число, может быть как положительным, так и отрицательным. Например, `-123`, `0`, `456`.
2️⃣**Float (действительное число)** — число с плавающей точкой. Используется для представления дробных чисел, например, `3.14`, `0.001`.
3️⃣**String (строка)** — последовательность символов, используется для работы с текстом. Например, `"Hello, world!"`.
4️⃣**Boolean (булев тип)** — имеет два значения: `true` (истина) и `false` (ложь). Используется для логических операций.

**Составные типы**
1️⃣**Array (массив)** — коллекция данных, которая может содержать элементы любого типа. Массивы в PHP могут быть как индексированными (с числовыми ключами), так и ассоциативными (с ключами-строками).

```php
      $array = [1, 2, 3]; // Индексированный массив
   $assocArray = ['name' => 'John', 'age' => 25]; // Ассоциативный массив
   
```

2️⃣**Object (объект)** — экземпляр класса, который содержит данные (свойства) и методы для работы с этими данными. Объекты создаются на основе классов.

```php
      class Car {
       public $color;
       function setColor($color) {
           $this->color = $color;
       }
   }
   $car = new Car();
   $car->setColor('red');
   
```

**Специальные типы**
1️⃣**Resource (ресурс)** — представляет собой ссылку на внешние ресурсы, такие как файлы, соединения с базами данных и т.д.
2️⃣**NULL** — тип, имеющий одно значение `NULL`, используется для обозначения переменной без значения.

Есть четыре основных скалярных типа данных (целые числа, дробные числа, строки, булевы значения), два составных типа (массивы и объекты) и специальные типы (ресурс и NULL). Каждый из этих типов данных используется для различных задач в программировании, что делает PHP мощным и гибким языком для разработки веб-приложений.
